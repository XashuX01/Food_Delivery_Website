# 🍔 Food Delivery Website

A modern and responsive Food Delivery Website built using **HTML**, **CSS**, and **JavaScript**.
This project allows users to browse food items, add products to the cart, and dynamically update cart totals.

---

## 🚀 Features

* Responsive Navigation Bar
* Mobile Menu Toggle
* Product Cards
* Dynamic Add to Cart System
* Quantity Increase & Decrease
* Live Cart Total Calculation
* JSON-based Product Data
* Swiper Slider Integration
* Clean & Modern UI Design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Swiper.js
* JSON

## ⚡ How to Run the Project

1. Clone the repository

```bash

```

2. Open the project folder

```bash
cd Food_Delivery_Website
```

3. Open `index.html` in your browser
